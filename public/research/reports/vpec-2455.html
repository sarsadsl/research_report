執行摘要
核心判斷：25Q4→26Q2 營收僅約 +0.6%，但毛利額 +4.2%、稅後淨利 +10.1%、EPS +9.5%，代表獲利品質先於營收加速改善。2026/07 單月營收 4.22 億創高，研究估計光電子占比已超過 40%，是 H2 結構改善的第一個高頻驗證點；但 26Q2 GM 38.61% 尚未達全年模型所隱含的 H2 41–42% 區間，因此目前評價仍應落在「黃綠燈之間、偏綠」。
研究主軸與驗證鏈
2026 驗證
  • H2 月均約 4.24–4.43 億
  • 光電子占比穩定 40%+
  • H2 毛利率往 41–42% 推進
  • OP / EPS 跟上 GP 改善
2027 驗證
  • 光電子占比接近 / 超過 50%
  • AI 光通訊成為主要營收增量
  • 光電子營收兩年 CAGR 接近 90%
  • 新機利用率與高價值產品放量
驗證鏈：InP 供應 → 新機 utilization → 光電子營收 → 光電子占比 → 毛利率 → 營益率 → EPS。任何一段失速，都應對 2027 模型折價，而不是只用設備台數推導營收。

解讀
目前最值得注意的不是 Q2 營收「只」成長多少，而是營收近乎持平時，毛利額、營業利益與 EPS 已先改善。這代表產品 mix / 售價 / 成本結構正在轉好；但 Q2 營益率較 Q1 小幅回落，因此 H2 必須看到營收放量與 GM 上升同時轉化到 OP margin，才能確認財務槓桿真正啟動。

07｜最終結論：紅綠燈觀察警示

綠＝主軸落地並轉成財務
黃＝方向對但數字未完全跟上
紅＝2027 高成長論述需下修
綠

發展順利

  • 月營收穩定 4.2–4.4 億以上
  • 光電子占比 >40%，往 45–50%
  • 毛利率 41–42%+
  • InP 供應 / 出口許可穩定
  • 新 MOCVD utilization 上升
  • 200G PD / CW Laser 明顯放量
  • OP margin / EPS 跟著 GM 改善
黃

待觀察

  • 月營收 4.0–4.2 億附近
  • 光電子占比停在 35–40%
  • 毛利率仍在 38–41%
  • InP / 許可偶有遞延
  • 設備到位但 qualification / 良率 ramp 慢
  • 營收成長但 OP / EPS 沒跟上
  • 2027 應使用折價後中位模型
紅

論述轉弱

  • 月營收連續 <4.0 億
  • 光電子占比掉回低 30%
  • 毛利率 <38%
  • InP / 出口許可再度卡關
  • 新產品認證 / 量產明顯延遲
  • 折舊先進來且營益率下降
  • 下修 2027 Revenue / GM / EPS
目前判讀
黃綠燈之間、偏綠。2026/07 營收創高且研究估計光電子占比已超過 40%，方向轉正；25Q4→26Q2 也已看到 GM / EPS 先改善。但 H2 尚需連續確認三件事：① 月營收能否穩定達 4.2–4.4 億，② GM 能否跨 40% 並往 41–42% 靠攏，③ InP 供應與新機 utilization 是否形成持續性，而非單月或單一設備事件。
模型影響與下一輪檢查
若轉綠
維持 / 上修 2027 中位模型，重點看光電子占比與 GM 是否同時超標。
若維持黃
保留成長方向，但對 2027 EPS / 估值折價，等待 utilization 與毛利率證據。
若轉紅
先下修光電子占比、GM 與 EPS，再評估新增產能是否造成折舊壓力。
資料口徑：已公布財報 / 公司公開資訊優先；市場模型以去識別化「市場共識」呈現；金玉峰等研究報告統一歸類為「投顧自研樂觀情境」。2026/07 光電子占比屬研究估計，不應視為官方分部揭露。
研究結論：現階段最重要的不是再找一個更高的 EPS 目標，而是持續驗證 InP → utilization → 光電子營收 → mix → GM → OP → EPS 是否連續成立。
