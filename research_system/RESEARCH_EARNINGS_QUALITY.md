# EQ-01｜盈餘品質與業外損益穿透檢驗（v1.0.0）

適用：2026-11-13 起新建及重新發行的所有個股 `full-research`「完整報告」（台股、美股與其他市場）。本規範增補 [Workflow](RESEARCH_WORKFLOW.md)、[Data Contract](RESEARCH_DATA_SCHEMA.md)、[QC](RESEARCH_QC.md)；不取代既有來源、版本、人工審閱與發布 gate。

## 原則與執行層級

**所有公司必須先做第一層檢查；任何觸發條件成立，才做第二層穿透。** 不得僅憑公司屬於科技業或權益法損益金額大，即把所有業外收入視為不合理。金融、控股、投資公司應先辨別其主要經營業務；與核心業務密切相關的投資收益不應機械式歸零。

| 層級 | 所有公司是否必做 | 完成證據 |
| --- | --- | --- |
| L1：標準篩檢 | 是 | 近三年及最近四季（可得範圍）損益橋接、業外分類、變動理由、來源、是否觸發、法定 EPS 與可驗證的常態 EPS／未能估算理由 |
| L2：異常穿透 | 任一觸發時必做 | 財報附註及附表對帳、投資標的／交易來源、已實現與未實現、現金與非現金、稅與非控制權益、股數、淨值／OCI、估值敏感度和結論 |
| L3：報告呈現 | 所有公司 | L1 未觸發：財務章節簡表；觸發：財務章節完整拆解、估值章節調整、風險及驗證清單；不必為無異常公司增加獨立大章 |

## L1｜每期必要欄位與驗證方式

- 期間：至少近三年年度和最近四季，若資料不可得須標出缺口及理由；法定財報、券商模型及研究推估分開。
- 基本橋接：營業利益、營業外淨額、稅前淨利、所得稅、歸屬母公司淨利、基本／稀釋加權平均股數、法定 EPS；金融等產業依其適用財報格式重分類並說明。
- 主要組成：利息、股利、匯兌、金融資產 FVPL、採權益法損益、處分損益及其他一次性項目；辨認 FVOCI／OCI 不直接進入當期損益。
- 同時檢查 YoY、QoQ 與現金流。來源必須可追溯至財報科目／頁碼／附註／附表，不能只引用新聞或券商摘要。
- 必須說明法定 EPS 與常態 EPS 的差異。若無法充分辨認稅後歸屬，標「待驗證」，不得以 0 代替、不得假裝有精確調整數。

## 觸發 L2 的門檻（內部研究規則，非法規／會計準則）

任一符合即觸發：

1. 單季 `|業外損益淨額| / |稅前利益|` ≥ **15%**，或全年 ≥ **10%**。
2. 業外損益同比或環比的**絕對金額**變化 ≥ **50%**，且變化金額 ≥ 最近十二個月稅前利益絕對值的 **5%**，或 ≥ 同期營收的 **1%**。
3. 已辨識的特殊／一次性或未實現損益，對歸屬母公司 EPS 的估算影響 ≥ **10%**；或未實現損益占相應稅前利益 ≥ **5%**。
4. 關聯持股、特殊投資、OCI、會計政策或其他評價調整，可能影響歸屬母公司股東權益 ≥ **5%**。
5. **不受量化門檻限制**：交叉持股／透過關聯企業間接持有自身股票、SPV、合併範圍／實質控制疑義、重大關係人交易、重大會計政策差異／調節、重編財報、重大估計變更，或分析師預估與可得事實的業外損益明顯矛盾。

**分母保護**：稅前利益接近 0 或為負時，百分比不具有穩定解釋力，不得以無限大或負號直接下結論；改用絕對金額、占營收比例、與現金流／資產比較，並交人工判斷。缺數標 NOT_RUN，不是未觸發。

## L2｜穿透程序

1. **辨識來源**：損益表 → 附註 → 附表 → 被投資公司財報／持股結構；對帳期間及幣別、權益比例、合併／權益法／FVPL／FVOCI 處理。
2. **分類**：經常性／非經常性、現金／非現金、已實現／未實現、營業性／投資性、母公司權益／非控制權益；對有實質營運的關聯企業，不機械式剔除全部權益法損益。
3. **EPS**：法定歸母淨利 → 逐項經濟實質調節（含相關所得稅與非控制權益）→ 正常化歸母淨利 ÷ 正確的加權平均基本／稀釋股數。逐項註明「已於前一步剔除」，防止重複扣減。
4. **淨值**：檢查金融資產／關聯企業市值、OCI、交叉持股、庫藏股及不同財報準則的調節；不能把投資標的所有資產都當成無價值，也不能把一份市值重複計入母公司淨值。
5. **估值**：P/E 使用可追溯的正常化 EPS；P/B 或 ROE 視實質經濟權益作調整；DCF／FCF 依現金流，避免把未實現投資收益當成自由現金流。反映風險的估值倍數折價只能作明示情境，不能假稱市場已認定。
6. **期後波動**：若投資收益與股價／匯率等市場價格連動，列出穿透敏感度、可得期後價格、估值日與未知條件，不將當期未實現變動視為次期固定收益或保證損失。

## 報告固定呈現欄位

| 欄位 | 必須說明 |
| --- | --- |
| 業外占比 | 分子／分母、期間、絕對值及例外處理；呈現主要組成 |
| 法定 EPS | 報告期間、基本或稀釋、來源 |
| 正常化 EPS | 逐項歸母稅後調節；若無足夠依據則「待驗證」及影響範圍 |
| EQ-01 狀態 | `PASS / WARN / FAIL / NOT_RUN`、觸發條件及檢查人／日期 |
| 估值影響 | 法定／正常化模型差異，是否已剔除，敏感度和風險 |
| 資料血緣 | `sourceIds`、`claimIds`、頁碼／附註、方法、版本與截止日 |

## 聯電（2303）案例｜測試情境，不是正式認證調節

2026 年前三季的權益法投資收益、關聯企業迅捷／焱元／矽統持有聯電股票、FVPL／FVOCI 差異，以及台灣編製財報與美國申報 20-F 採用的 **IASB IFRS** 調節，均符合 L2 觸發。應核對官方季報與可得最近年度 20-F 的科目、持股張數、比例、基準股價、稅務、歸母與 OCI。不能以文章估出的「約 170 億元／EPS 1.35 元」當成已經由官方財報認證的稅後調整，亦不得以「全數權益法損益歸零」取代正常化分析。

2027 年預測須分開：晶圓代工核心營業利益、真正可持續之投資收益與聯電自身股價引起的非經常性波動；將已正常化的 EPS 再額外折減一次是 **FAIL**。

## QC、發布與既有資料相容

- **立即適用**：新建及再發行的完整報告必須有 L1 審查紀錄；觸發 L2 而未完成穿透、缺重大來源／算式，或模型重複剔除 → 人工 **FAIL / BLOCKED**。
- **歷史報告**：不修改既有 published package／報告，也不追溯假稱已通過；下次新版發行時依新規審核。
- **現有系統界線**：本版是文件與人工 QC 規範。既有 `research:validate`、`research:check`、`research:publish` **尚未自動計算或強制 EQ-01**；`research_runs` 亦未保存 EQ-01 結果。未建置 validator、D1 schema、importer、renderer 與回讀驗證前，不要把範例 `earningsQuality` 字段直接當成機器契約或在 D1 手改資料。工程化須另立變更及回歸測試，並經原有發布 gate。
- **隱私與授權**：不將受限券商原始 PDF 或未獲授權資料提交公開 repo；只引用可公開的來源索引／摘要與合法可使用的研究推論。
